คุณจะกลายเป็น... YOU WILL BECOME

🛡
Cybersecurity Analyst

ตรวจสอบและวิเคราะห์ภัยคุกคามในระบบองค์กร

CYBERSECURITY ANALYST

Monitor and analyze security threats in enterprise systems.

⚔
Penetration Tester

ทดสอบเจาะระบบเพื่อค้นหาช่องโหว่ก่อนผู้โจมตีจริง

PENETRATION TESTER

Find vulnerabilities before attackers do — ethically.

🔬
Digital Forensics Analyst

สืบสวนหาหลักฐานดิจิทัลหลังเกิดเหตุโจมตี

DIGITAL FORENSICS ANALYST

Investigate digital evidence after security incidents.

🖥
SOC Analyst

ประจำศูนย์ปฏิบัติการด้านความมั่นคง ตอบสนองต่อเหตุการณ์แบบเรียลไทม์

SOC ANALYST

Operate security operations centers and respond to incidents in real time.

☁
Cloud Security Engineer

ออกแบบและรักษาความปลอดภัยของระบบคลาวด์

CLOUD SECURITY ENGINEER

Design and secure cloud infrastructure at scale.

🧬
Malware Analyst

วิเคราะห์โค้ดอันตรายเพื่อทำความเข้าใจและป้องกัน

MALWARE ANALYST

Reverse-engineer malicious code to understand and neutralize threats.

💼
Security Consultant

ให้คำปรึกษาองค์กรด้านกลยุทธ์ความมั่นคงปลอดภัย

SECURITY CONSULTANT

Advise organizations on security strategy and compliance.

👔
CISO / ผู้บริหารด้านความมั่นคง

บริหารนโยบายและกลยุทธ์ด้านความมั่นคงสารสนเทศทั้งองค์กร

CISO / SECURITY MANAGER

Lead organization-wide information security policy and strategy.

เรียนอะไรบ้าง? WHAT YOU WILL LEARN

01

ปีที่ 1 — พื้นฐาน

YEAR 1 — FOUNDATIONS

  • คณิตศาสตร์และสถิติ
  • ฟิสิกส์ประยุกต์
  • พื้นฐานคอมพิวเตอร์
  • การเขียนโปรแกรมเบื้องต้น
  • Mathematics & Statistics
  • Applied Physics
  • Computer Fundamentals
  • Intro to Programming
วิทย์-คณิต SCI · MATH

02

ปีที่ 2 — วิทยาการคอมพิวเตอร์

YEAR 2 — COMPUTER SCIENCE

  • โครงสร้างข้อมูลและอัลกอริทึม
  • สถาปัตยกรรมคอมพิวเตอร์
  • ระบบเครือข่าย
  • ระบบปฏิบัติการ
  • Data Structures & Algorithms
  • Computer Architecture
  • Computer Networks
  • Operating Systems
CS หลัก CORE CS

03

ปีที่ 3 — ความมั่นคงไซเบอร์

YEAR 3 — CYBERSECURITY

  • การทดสอบเจาะระบบ
  • นิติดิจิทัล
  • วิเคราะห์มัลแวร์
  • การเข้ารหัสและคริปโตกราฟี
  • ความมั่นคงคลาวด์
  • Penetration Testing
  • Digital Forensics
  • Malware Analysis
  • Cryptography
  • Cloud Security
ความมั่นคงไซเบอร์ CYBER CORE

04

ปีที่ 4 — โครงงานและฝึกงาน

YEAR 4 — PROJECT & INTERNSHIP

  • โครงงานอาวุโส (Senior Project)
  • สหกิจศึกษา (ฝึกงานอุตสาหกรรม)
  • หัวข้อขั้นสูงด้านความมั่นคง
  • Senior Project
  • Cooperative Education
  • Advanced Security Topics
